# CI: check and build on every push

Status: needs-triage

Run the project's checks on every push and pull request. See spec.

Remote: https://github.com/GiorgosKoulouris/LightCues (added 2026-10-08).

- GitHub Actions workflow on `windows-latest`, Node from `.nvmrc`.
- Steps: `npm ci`, `npm run check`.
- Once issue 01 lands: run `npm run package` and upload the installer as a workflow artifact.

## Acceptance

- A push to `dev` or a PR to `main` runs the workflow.
- A failing typecheck, lint, format check or test fails the run.
