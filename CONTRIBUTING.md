# Contributing

## Issues

Bug reports and Fixture requests are welcome as [GitHub Issues](https://github.com/GiorgosKoulouris/LightCues/issues/new/choose). Pick the template that fits. For a security vulnerability, use the [Security tab](https://github.com/GiorgosKoulouris/LightCues/security), not an issue.

## Pull requests

By arrangement: open an issue first and say what you want to change.

## Branches

Work happens on `dev`. It is squashed into a few commits on `stage`, checked by CI, then merged to `main`, which holds the released code.

Building, testing and the project layout: [docs/development.md](docs/development.md).
